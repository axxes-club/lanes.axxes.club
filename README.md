# Lanes — boards for every team

Kanban boards for AXXES workspaces (lanes.axxes.club). Uses the shared `projects` / `project_*` tables, so boards also appear as Projects in the AXXES Suite. Sign-in via Handshake.

> **Work in progress — paused.** Deploys are blocked by a Vercel limit. The
> logic layer is largely done and much of the UI is not. Start with
> [`docs/README.md`](./docs/README.md) — it has the state of play, the
> architecture decisions, the data model, the API surface and an ordered
> backlog. The one-line version: five modules of finished logic (roles,
> permissions, sprints, poker, insights) have **no screen attached yet**.
